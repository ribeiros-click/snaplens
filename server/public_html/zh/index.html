常见问题

macOS 提示无法打开应用，怎么办？

当前版本未经 Apple 公证。右键点击 SnapLens → 打开 → 打开。仅首次需要。然后在“系统设置 → 隐私与安全性”中允许“屏幕录制”。

哪些数据会离开我的 Mac？

除非你主动操作，否则什么都不会：OCR 和标注都在本地运行。只有分享按钮会把图片上传到 lens.ribeiros.click，只有“AI 描述”会把图片发送给你配置的提供商。参见隐私政策（葡萄牙语）。

分享需要账户吗？

不需要。上传是匿名的，按 IP 限流以防滥用。你会获得删除令牌，可随时删除图片。

可以使用自己的链接服务器吗？

可以。后端是纯 PHP，可自行托管，服务器地址可在“设置 → 分享”中配置。

价格多少？

免费。应用免费、无订阅、无广告。外部 AI 提供商按用量在你自己的账户计费。

支持 Intel Mac 或旧版 macOS 吗？

该版本面向 Apple Silicon，需要 macOS 15（Sequoia）或更高版本，因依赖 ScreenCaptureKit 和系统翻译器。

准备好更好地截图了吗？

拖入“应用程序”并按 ⌥⌘P。
