Frequently asked questions

macOS says the app can't be opened. Now what?

The current build isn't notarized by Apple. Right-click SnapLens → Open → Open. Only needed the first time. Then allow “Screen Recording” in System Settings → Privacy & Security.

What leaves my Mac?

Nothing, unless you ask: OCR and annotations run locally. Only the share button uploads the image to lens.ribeiros.click, and only “Describe with AI” sends the image to the provider you configured. See the Privacy Policy (Portuguese).

Do I need an account to share?

No. Uploads are anonymous and rate-limited per IP to prevent abuse. You get a delete token to remove the image whenever you want.

Can I use my own link server?

Yes. The backend is plain, self-hostable PHP, and the server address is configurable in Settings → Share.

How much does it cost?

Nothing. The app is free, with no subscription and no ads. External AI providers bill usage on your own account.

Does it work on Intel Macs or older macOS?

The build targets Apple Silicon and requires macOS 15 (Sequoia) or later, because of ScreenCaptureKit and the system translator.
